# Claude Max 5x 和 20x 区别：功能完全一样、价格差一倍，用量到底差几倍、哪档才值得买

会搜索这个问题的人，通常已经在 Pro 上撞过一次额度墙了。接下来的纠结很具体：多掏 100 美元，到底买到的是新功能，还是只是"能多用一会儿"？

先把最容易误会的部分说清楚。Max 5x 和 Max 20x 不是两个产品，是同一个产品的两种用量档位。模型、功能、权限清单基本重合，你多付的钱只买一样东西——在额度用完之前能连续工作多久。

## 5x 和 20x 指的是"每个 5 小时会话"的用量倍数

官方帮助中心的表述是：Max 5x 提供每个会话 Pro 的 5 倍用量，Max 20x 提供每个会话 Pro 的 20 倍用量。会话额度按 5 小时滚动窗口重置。

注意这里的主语是"会话"，不是"一周"，也不是"一个月"。这是后面所有争议的源头。

Anthropic 从来不公布各档对应的绝对 token 数，只给相对倍数。原因其实不难理解：一条消息消耗多少额度，取决于你写多长、带多大附件、当前对话已经堆了多少内容、有没有调用工具、选的是哪个模型。同一档位的两个用户，一个下午的产出可能差好几倍。所以任何告诉你"20x 每月能发多少条消息"的说法，都是估算。

还有一个容易踩的坑：Claude 网页聊天、Claude Code 和 Cowork 共用同一个额度池。下午在终端里让 Claude Code 读仓库、改文件、跑测试，消耗的额度同时会吃掉晚上聊天的余量。重度终端用户尤其要按这个逻辑算账。

## 功能层面，两档没有区别

把官方帮助中心列出的权益逐条排下来，除了用量倍数，其余每一项都同时挂在两个档位上：

| 功能 | Max 5x | Max 20x |
| --- | --- | --- |
| 用量倍率（相对 Pro，按 5 小时会话） | 5 倍 | 20 倍 |
| Claude Code 访问 | 包含 | 包含 |
| Cowork（桌面端多步骤任务委派） | 包含 | 包含 |
| 更高的输出上限 | 包含 | 包含 |
| 高峰期优先访问 | 包含 | 包含 |
| 新模型 / 新功能优先体验 | 包含 | 包含 |
| 年付优惠 | 无 | 无 |
| 标准折扣定价 | 无 | 无 |

官方明确说明，Max 计划目前只提供月度订阅。也就是说，别指望"一次付一年把价格压下来"——Max 没有这条路，Pro 才有年付。官方也写明不为任何付费计划（包括 Max 5x 和 20x）提供标准折扣定价，所以第三方渠道宣称的"官方折扣价"值得多问一句。

关于上下文窗口，网上的说法互相矛盾，有的写两档同为 200k，有的写 Max 在 Opus 上可以用到 100 万 token 的扩展上下文。这个问题上的公开信息不够一致，建议不要把它当成选档依据。真正区分两档的只有用量。

## 价格拆开看：20x 的单价更便宜，但前提是你真的用满

Web 订阅价格是固定的两档：Max 5x 每月 100 美元，Max 20x 每月 200 美元（移动端价格可能不同）。

把价格除以倍数，单位成本就很清楚了。5x 每买到一个"Pro 单位"的用量要花 20 美元，20x 只要 10 美元。这个账只有在一种情况下成立：你在 5x 上确实经常打满。否则多付的 100 美元买回来的是一堆不会用完的额度。

两个细节值得单独拎出来：

- **别在手机 App 里下单。** 有第三方对 App Store 页面的核对显示，Max 5x 在 iOS 内购是每月 124.99 美元，比网页版贵约 25%，一年下来多花接近 300 美元，买的是完全一样的订阅。
- **两个 5x 账号的钱等于一个 20x。** 总额度看起来能凑齐，但那是两个独立账号，额度不能合并，对话历史和登录也是两份。只在你确实需要两个彼此隔离的工作身份时才算值。

## 20x 不等于"每周 4 倍"，这是争议的核心

如果 5x 和 20x 的差别只有"每小时能用多少"，那这个话题不会闹到法庭上去。

问题在于还有第二层限制：每周额度。这个每周上限是后来引入的，Max 档位下有两个——一个覆盖所有模型，一个专门针对 Sonnet 模型。两者都按固定时间重置，开始用 Claude 的时间或者订阅开始的时间都不会改变这个重置点。

TechCrunch 引用过一份 Anthropic 在 2025 年 7 月发给订阅用户的邮件，里面给出的每周参考数字是：

- Pro（20 美元/月）：40 到 80 小时 Sonnet 4
- Max 5x（100 美元/月）：140 到 280 小时 Sonnet 4，外加 15 到 35 小时 Opus 4
- Max 20x（200 美元/月）：240 到 480 小时 Sonnet 4，外加 24 到 40 小时 Opus 4

按这些区间取中值算，翻倍的钱换来的是大约 1.7 倍的每周额度，不是 4 倍。也正是在这个数字上，有用户在美国加州北区联邦法院提起并扩展了集体诉讼，主张"5x / 20x"的宣传与实际到手不符，称实际只有 6 到 8 倍。案件截至目前没有实质裁决，Anthropic 也未就诉讼公开回应。

这里不必替任何一方下判断，但有一条实用结论：**你日常撞到的多半是每周额度，而不是 5 小时窗口。** 所以选档时该问的不是"我一天用几小时"，而是"我一周里有没有几次会把周额度啃掉一大块"。

真的不够用时，还有一条官方通道：Claude Code 里可以开启用量额度，按 API 标准费率购买追加用量，聊天和 Claude Code 都适用，Pro 和 Max 都支持，另有每日兑换上限。它适合偶尔的突发需求，不适合长期替代订阅。

## 到底选哪个：三个判断标准

**先看 Pro 的表现。** 如果你一个月只碰到一两次额度提示，升级是浪费。额度提示每周固定出现好几次，说明 5x 是合理起点。每天在 Claude Code 里跑 6 小时以上的长任务、做跨文件重构、跑整夜代理流程，那 20x 更像刚需。

**沿着阶梯升，不要跳级。** Free → Pro → Max 5x → Max 20x，每一档都跑到确实卡住再往上走。直接上 20x 的人里，有相当一部分其实在 5x 上就够用了。

**三种情况别买 Max。** 需要多人共用的话，Max 是个人档位，共享得看团队方案；只是偶尔写点东西、做点总结，Pro 的额度通常够；把订阅当 API 用也不行，额度用完就是等重置，无人值守的自动化任务更适合按量计费的 API。

## 常见问题

**Max 20x 会解锁 5x 没有的功能吗？**
不会。两档包含的模型、Claude Code、Cowork、输出上限和优先访问权限相同，差别只在用量。

**两档能年付省钱吗？**
不能。Max 目前只提供月付，官方也不提供付费计划的标准折扣定价。

**什么时候该从 5x 升到 20x？**
当你在 5x 上每周都会撞到额度上限，并且工作因此中断的时候。只是偶尔碰到，那 100 美元的差价换不回相应的价值。

**升级或降级方便吗？**
官方表示档位可以按需求变化调整，具体生效细节以订阅页面当前的说明为准。

**两档用同一个模型吗？**
是。倍率衡量的是容量，不是模型质量。
